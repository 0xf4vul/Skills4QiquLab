## 库用法

**找到 Skill → 阅读对应 Skill 文件 → 按 Workflow 执行 → 使用模板 → 查看示例 / 评测 → 修改复用**

- **方法论** → skills/
- **完整工作流** → cases/
- **创建新 Skill** → Skill Builder + Skill Template

每个 Skill 内部均包含 **用途 / 使用场景 / Workflow / 边界或失败模式 / Evaluation**，可直接进入对应文件使用，无需先阅读整个仓库。

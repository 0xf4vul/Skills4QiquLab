## 库用法

**选择 Skill → 打开对应 Skill 文件 → 按 Workflow 执行 → 使用模板 → 查看示例 / Evaluation → 修改复用。**

每个 Skill 内部均包含 **Purpose / Use / Workflow / 边界或失败模式 / Evaluation**；Cases 提供完整实战工作流。

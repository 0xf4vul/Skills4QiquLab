## How to Use the Library

**Find a Skill → read its Skill file → follow its workflow → use its templates → check examples / evaluation → adapt and reuse**

- **Method** → skills/
- **Complete workflow** → cases/
- **Create a new Skill** → Skill Builder + Skill Template

Every Skill contains its own **purpose / use / workflow / boundaries or failure modes / evaluation**, so it can be used directly without reading the whole repository first.

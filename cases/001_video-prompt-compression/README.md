Compress video prompts while preserving action chains, temporal relationships, camera logic, and subject continuity.

## Use

**Read SKILL.md → choose a template → reference examples → run evaluation → reuse**

## Important structure

`SKILL.md` — core method · `templates/` — prompt templates · `examples/` — examples / failures · `evaluation/` — evaluation

## Boundary

Do not compress away the action semantics required for the video to remain coherent.

# Evaluation Rubric

## A. Semantic preservation

- Subject identity
- Action identity
- Action order
- Temporal relationships
- Causality
- Camera behavior

## B. Execution quality

- Prompt clarity
- Temporal coherence
- Motion continuity
- Model executability

## C. Compression quality

- Redundancy removed
- Information density improved
- No invented semantics

## Result

**Pass** / **Revise** / **Reject**

A shorter prompt is not automatically a better prompt.

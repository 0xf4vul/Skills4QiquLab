# 002 — Source-to-KOL Research

</div>

> 其他语言：[English](README.md) · [繁體中文](README.zh-TW.md)

将名单、网页、文章、社交内容、视频/播客、PDF、截图或链接转化为可验证、可复核、可审计的 KOL / 专业信息源研究流程。

## 项目亮点

- **来源到人物可追溯**：记录人物从哪里被发现，以及在原始来源中扮演的角色。
- **身份核验分层**：严格区分“发现候选账号”和“确认账号归属”，并保存身份证据。
- **30 天活动审计**：区分完整时间线、部分时间线与无法取得的时间线，不用缺失数据进行估算。
- **跨平台实体解析**：处理同名、账号归属、职位角色与平台差异，避免错误匹配。
- **证据优先的名单输出**：将身份状态、活动证据、内容主题与信息源价值分开记录。

## 项目结构和说明

| 路径 | 说明 |
|---|---|
| `SKILL.md` | 完整研究方法、身份规则、30D 审计规则、输出契约与硬规则 |
| `templates/` | 来源采集、搜索计划与研究结果表模板 |
| `examples/` | 实际研究案例与参考输出 |

## 库用法

**阅读 SKILL.md → 选择输入模式 → 收集证据 → 核验身份 → 审计 30D 活动 → 分类内容 → 形成名单**

完整方法见 [SKILL.md](SKILL.md)；审计规则见 [evaluation/](evaluation/)；研究模板见 [templates/](templates/)。

## 核心原则

确认来源角色 → 确认人物 → 确认账号 → 确认时间线 → 将活跃度与信息源价值分开。

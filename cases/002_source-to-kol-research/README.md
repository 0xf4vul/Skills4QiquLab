# 002 — Source-to-KOL Research

</div>

> Read this in other languages: [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md)

Turn arbitrary source material into a verifiable, auditable workflow for discovering and validating KOLs and professional information sources.

## Highlights

- **Source-to-person traceability** — preserves where each person or account was discovered and what role they played in the source.
- **Identity verification** — separates candidate discovery from identity confirmation and records evidence explicitly.
- **30-day activity audit** — distinguishes complete timelines from partial or unavailable timelines instead of estimating missing data.
- **Cross-platform entity resolution** — handles same-name collisions, account ownership, roles, and platform differences.
- **Evidence-first shortlist** — separates identity status, activity evidence, content signals, and information-source value.

## Usage

**Read SKILL.md → select an input mode → collect evidence → verify identity → audit 30D activity → classify content → build shortlist**

For the complete method, see [SKILL.md](SKILL.md). For audit rules, see [evaluation/](evaluation/). For reusable research forms, see [templates/](templates/).

## Principle

Verify the source role → verify the person → verify the account → verify the timeline → separate activity from information-source value.

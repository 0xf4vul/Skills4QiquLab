# 002 — Source-to-KOL Research

</div>

> 其他語言：[English](README.md) · [简体中文](README.zh-CN.md)

將名單、網頁、文章、社交內容、影片 / Podcast、PDF、截圖或連結轉化為可驗證、可複核、可稽核的 KOL / 專業資訊源研究流程。

## 專案亮點

- **來源到人物可追溯**：記錄人物從哪裡被發現，以及在原始來源中扮演的角色。
- **身份核驗分層**：嚴格區分「發現候選帳號」與「確認帳號歸屬」，並保存身份證據。
- **30 天活動稽核**：區分完整時間線、部分時間線與無法取得的時間線，不使用缺失資料估算。
- **跨平台實體解析**：處理同名、帳號歸屬、職位角色與平台差異，避免錯誤匹配。
- **證據優先的名單輸出**：將身份狀態、活動證據、內容主題與資訊源價值分開記錄。

## 儲存庫用法

**閱讀 SKILL.md → 選擇輸入模式 → 收集證據 → 核驗身份 → 稽核 30D 活動 → 分類內容 → 形成名單**

完整方法見 [SKILL.md](SKILL.md)；稽核規則見 [evaluation/](evaluation/)；研究範本見 [templates/](templates/)。

## 核心原則

確認來源角色 → 確認人物 → 確認帳號 → 確認時間線 → 將活躍度與資訊源價值分開。

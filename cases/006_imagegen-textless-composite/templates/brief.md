# Card Brief — 无字底图 + 精确叠字

出图前先把需求填完。**三分钟填表，省掉三次重生。**

```text
## 1. 用途与画幅
用在哪：公众号封面 / 插图 / 小红书 / 小绿书 / 金句卡 / 海报
画幅：横版 1536×1024 / 方形 1024×1024 / 竖版 1024×1536
最终发布比例：16:9（1600×900）/ 1:1（1080×1080）/ 3:4（1080×1440）

## 2. 色板（先于出图，写进 prompt）
主色（底）：#0E1A2E
辅色（强调）：#E8A33D
点缀（正向）：#5CD6A6  —— 只用于优势/结论
文字：#F4F6FA，次级 #96A8C6

## 3. 底图 prompt
主体描述：
场景氛围：
质感风格：
负面词块（必带）：Absolutely no text, no letters, no words, no numbers, no watermark, no logo.

## 4. 文案（全部叠字，禁烧进图）
主标题（≤11 字/行）：
副标题 / 说明：
关键数字（带单位，须有出处）：
CTA：

## 5. 减法清单（重要）
画面里不该出现什么：
  例：不要水印、不要文字、不要 logo、不要数字

## 6. 自检
- [ ] 底图四角无字无 logo
- [ ] 每个数字有原文出处
- [ ] 字体含汉字、无豆腐块
- [ ] 4 个 hex 照抄色板
- [ ] 水印已清
- [ ] 文字对比足够
- [ ] 文案未溢出
- [ ] 成套同色同字体
```

## 填写要点

**减法清单最容易漏，也最有用。** 底图本来就无字，所以这里要锁死的是「绝不把文字/数字/logo 写进 prompt」——图内烧字是毁掉一张好卡最常见的方式。

**色板先想发布位。** 公众号封面 16:9，正文图 1:1，小红书/小绿书 3:4。生图尺寸和发布比例不同没关系，色板与字体保持一套即可。

**数字必须可溯源。** 封面上任何一个数字错一位就是硬伤，填表时就把出处标清楚。

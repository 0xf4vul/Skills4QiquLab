# Acceptance Checklist — Textless Backdrop + Precise Type Overlay

八条出图自检。任何一条不过，改 spec / prompt 重出，**不要直接交付**。

## 1. 底图确实无字

反面：模型把标题、数字、logo 烧进了图。
检查：放大看底图四角与主体区，有没有任何字母、数字、水印、logo。

## 2. 每个数字都能在原文找到出处

反面：卡片上的 `$0.71` / `44 分` 是编的或算错的。
检查：逐个数对回原文，单位（分 / 美元 / 百分比）也核对。

## 3. 字体是真的，没有豆腐块

反面：标题出现 `□□` 缺字或异形字。
检查：`find_font.py` 报告字体含 CJK 字形；关键标题字单独放大看。

## 4. 配色锚定账号色板

反面：叠上去的字和底图一个暖一个冷，压不住。
检查：4 个 hex 全部照抄色板；辅色（琥珀金）只用在强调位，薄荷绿只用于优势/结论。

## 5. 水印已清干净

反面：右下角残留「AI 生成」条。
检查：裁切后看右下角 90×60 px；裁不掉的看覆盖区有没有色差。

## 6. 文字对比足够

反面：浅字压在亮底上，看不清。
检查：必要时压暗条（纯色 + alpha mask），正文区与底图亮部对比够。

## 7. 文案不溢出画布

反面：标题冲出右边或底部。
检查：`render_card.py` 自带字号自适应 + 自动纵向流动；极端长文案跑一次 `--demo` 验证。

## 8. 成套物料风格统一

反面：主图一套色，细节卡另一套色。
检查：同底色、同辅色、同字体、同隐喻；主图与细节卡用同一 spec 基。

## 用数值验证（看渲染报告）

`render_card.py` 的 `selftest.py` 与 `--demo` 会输出断言，覆盖：字体探测、找到的字体确实含汉字、豆腐块识别器不误判纯拉丁字体（5 个真实拉丁字体反例）、端到端渲染、输出尺寸、极端长文案不崩、**长文案未溢出右边界**、去水印两模式、尺寸变化正确、**半透明图层 alpha 回归**（防「RGB 上 alpha 被静默丢弃」再次发生）。

### 实测教训：RGB 上画半透明会静默失效

```python
draw.rounded_rectangle(box, fill=(232,163,61,26))   # ✗ alpha 被忽略，画成实心
```

后果：叠在色块上的字看不见，或色块死板。正解：所有带 alpha 的元素画在独立 RGBA 图层上再 `alpha_composite`。

### 实测教训：双色渐变当压暗条会把底部刷白

`vgrad(top, bottom)` 若 `bottom` 传白色，底部整片变白。压暗条一律用「纯色 + 逐行 alpha mask」。

## 迭代原则

1. **一次只改一个块**（pill / title / number / text / list / footer）。
2. **文字问题永远走叠加**，不要回到 prompt 里修。
3. **底图主体与标题区打架**，先 `transpose(Image.FLIP_LEFT_RIGHT)` 镜像，别重出图。
4. **压暗条只用纯色 + alpha mask**，不要双色渐变。

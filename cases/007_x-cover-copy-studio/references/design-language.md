# Design Language — 参考图共同规律与配方

## 一、X 推文封面通用规律(从 7 张参考图提炼)

1. **信息密度高但层级极分明** — 巨字标题抓第一眼, 列表/流程图给第二眼, 小字兜底。
2. **横版宽幅优先**(约 2.5:1 至 16:9) — 适配时间流预览, 核心信息必须在未点开时就读全。
3. **卖"具体内容"而非概念** — 海报上直接放 10 大场景 / 4 步流程 / 7 条清单, 数字即承诺。
4. **双色强调体系** — 黑白灰底 + 1 主强调色 + 1 点缀色(红/荧光绿/琥珀黄), 高亮块衬关键词。
5. **材质感制造记忆点** — 噪点/纸张纹理、硬阴影(无模糊)、3D 字、等轴测图, 至少占一样。
6. **列表项 = 编号块 + 名称 + 一句价值点**, 三件套横向节奏统一。

## 二、paper 主题配方(复古印刷情报风)

- 底色 `#EFE8D6` 米黄纸 + feTurbulence 噪点 SVG(multiply, opacity .55)
- 墨色 `#141210`, 强调红 `#C8321E`, 灯下黄 `#E8B830`
- 字体: Noto Sans SC 900(标题)/700(正文), IBM Plex Mono(域名/编号/英文装饰)
- 关键词黑底反白斜贴块 + 红色删除线; 贴纸块 = 纯色偏移硬阴影 `6px 6px 0`
- 元信息条、虚线分隔、胶囊标签、红色 CTA 横幅收尾

## 三、dark 主题配方(深色图鉴风)

- 底色 `#141210` + 双 radial 红/黄氛围光 + feTurbulence 噪点(overlay)
- 纸白 `#EFE8D6` 作主文字/边框色, 红 `#E04428` / 琥珀 `#E8B830` 强调
- 巨型空心水印(`-webkit-text-stroke`)压角; 双列虚线卡片图鉴; BONUS 卡留呼吸位
- 标题可用: 描边字 + 删除线 + 黄底斜贴高亮混排

## 四、字体加载(勿改)

```
family=Noto+Sans+SC:wght@500;700;900
family=IBM+Plex+Mono:wght@500;700
family=Noto+Color+Emoji   ← Linux 沙箱需显式引入, 否则 emoji 变 tofu
```
渲染等待 ≥7s 或 `--wait-for-timeout` 兜底, 防字体未加载出细体。

## 五、已验证布局预算(paper)

canvas 830 = padding 40/34 + meta 36 + main **固定 610** + foot 72(margin-top:auto)。
行高公式: row = 40px 编号块 + 4px×2 padding + 2px×2 border ≈ 54 → 7 行 378 ✓(>590 则 FAIL)。
黑屏大坑: `.main` 用 flex 自然高度会把 `.foot` 挤出画布 → 必须固定高度 + overflow 监控。

# Copy Formulas — 推文变体与封面文案配方

## 〇、总公式: 保留骨架, 只换血肉

```
[emoji 开场钩子 + 痛点反问] → 数字承诺(N 个工具闭眼收藏 👇)
→ 编号列表: URL + 破折号 + 一句价值点 → [🧷 收藏钩子收尾]
```
变体只改表达层; 域名、数量、功能事实不许动(红线见 §四)。

## 一、开场钩子库(痛点反问式)

- 2026 年了还在用 X 找 Y? 这些工具将取而代之
- 设计师的灵感收藏夹, 早就该换血了
- 同行不会告诉你的 N 个网站, 我替你试完了
- 把 "还在 XX" 花 10 分钟看完这篇, 你会回来谢我
- 免费 = 原罪? 这 N 个站我不允许有人没收藏

## 二、条目改写句式(URL 后的破折号部分)

| 原描述层 | 改写句式 | 例 |
|----|----|----|
| 功能罗列 | 变成动作收益 | "微动效与交互细节" → "瞬间提升质感的高级微动效, 照抄就行" |
| 名词 | 变成时间承诺 | "每日精选" → "每天 5 分钟, 看完全球最新佳作" |
| 抽象 | 变成反差 | "CTA 设计" → "按钮怎样设计, 用户才忍不住点" |
| 平铺 | 埋损失厌恶 | "导航栏设计范式" → "一个导航栏, 也有 100 种卷法" |

每条 ≤ 18 个汉字, 动词优先, 数字优先。

## 三、结尾 CTA 变体

- 记得先收藏, 以免遗忘 🧷
- 先 🧷 收藏 = 赚到, 划走就真的找不回来
- 转给那个还在熬夜找灵感的设计师朋友 ↗️
- 完整版放评论区, 收藏这篇就够了 ⬇️

## 四、红线(商用安全)

1. 不改写事实: 数量(500+/100+)、能力、免费与否必须与原文一致
2. 不用"最/第一/唯一"外新增未验证的绝对化宣称(广告法风险)
3. 不虚构背书("XX 大厂在用"类)
4. emoji 数量克制: 开场 1 + 引导 1 + 收尾 1, 列表内不放

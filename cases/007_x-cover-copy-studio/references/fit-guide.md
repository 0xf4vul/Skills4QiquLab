# Fit Guide — 适用情况 / 出图效果 / 使用边界

> 定位一句话: 本 Skill 是「**清单体推文 → 投放级图鉴海报**」的专业模具。
> 模具内确定性极高(硬上限拦截、幂等出图、质检可审计); 模具外请换工具。
> **口诀: 推文里数得出 "1. 2. 3..." → 用它; 数不出 → 别硬用。**

## 一、甜蜜区(效果最佳)

| 维度 | 最佳条件 | 原理 |
|---|---|---|
| 内容结构 | 编号清单型推文: N 个工具/资源/步骤/站点, 每条可压成「域名 + ≤14 字价值点」 | 双版式均为行列式图鉴, 天然吃列表 |
| 条目数 | paper ≤7 行; dark ≤7+1 卡 | 设计硬契约, 超出即拦截, 保证零残图 |
| 语言 | 中文为主 + 短英文域名 | Noto Sans SC 900 标题 × Plex Mono 域名, 双语节奏即设计母题 |
| 事实密度 | 有真实数字可摆(500+ / 100+ / 每日) | 高亮块靠数字驱动视觉重量 |
| 投放场景 | X / 微博 / 即刻等文字流平台单图或首图 | 2.41:1 贴横幅参考风格; 16:9 为时间流安全裁切线 |

## 二、边界外(会退化或不应使用)

1. **纯观点/叙事推文(无清单骨架)** — 没有行可摆, 退化为大字报封面; 此场景任意海报工具即可, 体现不出本工程质检链路的价值
2. **需真实产品截图/人物素材** — 双模板为纯排版型, 不支持嵌图; 硬改模板会绕过布局预算约束, 质量失去保证
3. **超长条目(>18 汉字/条)** — 域名可自动换行(L5 已验证), 但 desc `nowrap` 是设计选择, 长句会顶满行宽牺牲呼吸感; 应拆轮播多图
4. **英文为主推文** — 可渲染, 但「复古纸感情报风」的钩子/收藏句式源自中文社媒语感, 英文变体会水土不服
5. **平台级广告合规投放(品牌正式广告)** — 红线库仅覆盖广告法绝对化用语与事实层; 商标/行业审核规则不在射程内
6. **动图/视频封面** — 静态 PNG 管线, Playwright 每页只出一帧

## 三、出图质量杠杆(实测得出)

- **行距节奏最稳区间**: desc 8–14 字、域名 ≤20 字符 → 版面权重最均衡; 域名 >40 字符虽不塌但视觉重心右移(长域名会换行)
- **emoji 用量**: 全图 ≤3 个(开场/引导/收尾各一)最贴参考图气质; 多于 3 个滑向微商风
- **色彩纪律**: 保持「墨底 + 红 + 琥珀」双色体系; 引入第三强调色会破坏复古印刷统一性
- **specs 四格**: 放真实数字承诺(“500+ 提示词”), 不放形容词
- **行数为 5–7**: 7 行满编气势最足; 5–6 行 space-between 疏朗亦佳; ≤4 行建议改用 dark 单列或缩小标题层级

## 四、如何判断该不该调用本 Skill(给 Agent 的门禁)

- 输入含 ≥3 个并列条目且条目可提炼「名称+一句价值」→ 调用
- 输入无清单结构但用户坚持要「封面」→ 产出仅单张大字报式 paper(去掉列表区), 并口头降级声明
- 条目 8–14 个 → 引导拆分或换 dark; ≥15 个 → 拒绝模具, 建议轮播/图集方案

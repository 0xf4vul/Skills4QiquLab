# Style Checklist — Pencil Sketch Art

八条出图自检。任何一条不过，改 prompt 重生，**不要直接交付**。

## 1. 一眼是铅笔画的

反面：看起来像照片、像数字绘画。
检查：主体轮廓是否有石墨颗粒感，而不是平滑渐变。

## 2. 能看见排线笔触

反面：明暗靠大面积灰面糊过去。
检查：阴影区有没有密集交叉排线，中间调有没有稀疏单向排线。

## 3. 纸纹可见，背景非纯白

反面：纯白背景 —— 一秒变数字绘画。
检查：背景是不是米白 / 浅灰，能不能看到纸张颗粒。

## 4. 线条略有抖动，不是矢量

反面：轮廓干净得像 Illustrator 描边。
检查：轮廓线有没有断续、粗细变化、手工跳动。

## 5. 无塑料感 / 3D / 油画

反面：表面反光、材质光滑、笔触像油彩。
检查：有没有高光斑、有没有体积渲染感。

## 6. 色彩 ≤ 1 个色相

反面：彩色插画。
检查：除主体黑白灰外，是否只有一种低饱和点缀色（赭石 / 淡靛蓝 / 暗红）。

## 7. 图内文字 ≤ 8 字

反面：模型烧进图里的字是糊的、错字的。
检查：`build_prompt.py -t` 超过 8 字会直接报错拦下，这是硬闸门。**大段文字一律走无字底图 + 排版叠加。**

## 8. 留白区够叠字

反面：主体顶满了画面，标题没地方放。
检查：见下方"用数值验证"。

## 用数值验证（看不到图也能做）

`crop.py` 的墨量剖面不只用来裁图，还能反过来回答自检 8：

```bash
python scripts/crop.py --in raw.png --ratio 2.35 --bottom-safe 0.26 --dry-run
```

输出逐行墨量剖面 + 干净带位置。读法：

- **背景基准**取墨量中位数，不是最大值。纸纹本身有灰度，用 `max × 0.18` 当阈值会把整幅判成内容。
- **内容行** = 墨量 > `bg + (max-bg) × 0.30`。
- **干净带** = 连续墨量 ≤ bg 且长度 ≥ 120px 的区间 —— 这才是标题能叠的位置。

### 实测教训：留白约束会失效

给主图写了"上三分之一必须留白"，模型没遵守。墨量数据显示主体从 y=125 就开始。

原因：**垂挂类主体**（绳、管道、树、电线）物理上必须从边缘延伸进来，模型会自觉连到画面顶端，构图句拦不住。

应对：不要重复生成。用墨量剖面找真正干净的区间，把标题叠在那里。

## 迭代原则

1. **一次只改一个桶**（媒介 / 笔触 / 光影 / 纸 / 色 / 质量 / 负面 / 构图）。改多项就分不清哪项起了作用。
2. **先加正向，再加负面**。出图不像手绘，先加笔触桶，别急着堆负面词。
3. **两次无效就换预设**，不要在同预设里死磕。
4. **文字问题永远走排版**，不要回到 prompt 里修。

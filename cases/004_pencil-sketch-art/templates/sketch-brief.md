# Sketch Brief

出图前先把需求填完。**三分钟填表，省掉三次重生。**

```text
## 1. 主体
原文/原话：
主体类型：人物 / 物件 / 场景 / 抽象概念
如果是概念，转译成：（一个具象物件 + 一个动作）
  例：内卷 → 一个人在跑步机上原地跑，跑步机插着一面狂转的钟

## 2. 用途与画幅
用在哪：公众号封面 / 正文配图 / 小红书 / 金句卡 / 视频号
画幅：方形 1024² / 横版 1536×1024 / 竖版 1024×1536
最终发布比例：2.35 / 3:2 / 3:4 / 9:16 / 2:3

## 3. 情绪与笔触
想让人感觉：沉 / 暖 / 冷 / 轻 / 荒诞
笔触预设：1 线稿 / 2 排线 / 3 炭笔 / 4 淡彩 / 5 场景 / 6 概念隐喻
点缀色：无色 / 赭石 / 淡靛蓝 / 暗红

## 4. 文字
图内文字：无（推荐）
或 ≤ 8 字：
标题叠放位置：顶部 / 底部 / 由墨量剖面决定

## 5. 减法清单（重要）
画面里不应该出现什么：
  例：不要水表、不要计价器、不要钟在顶部

## 6. 自检
- [ ] 主体类型已定，概念已转译
- [ ] 画幅与发布比例已换算
- [ ] 笔触预设已选
- [ ] 图内文字 ≤ 8 字或留空
- [ ] 减法清单已写进 prompt
```

## 填写要点

**减法清单最容易漏，也最有用。** 画面里"少了什么"往往比"多了什么"更贴合金句——算盘要扣下、水表要缺席、台灯要关掉。

**概念转译的检验标准**：能不能画出来。凡是画不出来的（内卷、焦虑、阶层），都必须先落到一个物件和一个动作上。

**画幅先想发布位。** 公众号封面 2.35，正文图宽 ≤1080，小红书 3:4，视频号 9:16。生图尺寸和发布比例不同没关系，用 `crop.py` 裁，不用重生。

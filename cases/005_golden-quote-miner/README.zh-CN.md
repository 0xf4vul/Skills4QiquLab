# 005 — 金句提炼

</div>

> 其他语言：[English](README.md) · [繁體中文](README.zh-TW.md)

把一篇长内容，变成 5-12 句**能脱离原文单独活下来**的句子。纯文本交付，不依赖任何排版或绘图流程。

## 项目亮点

- **四层筛选漏斗**：候选扫描 → 密度过滤 → 张力四维打分 → 可脱离语境检验。每层都有明确淘汰标准，不是凭感觉挑。
- **`scan.py` 跑第一层**：断句 + 判词 / AI 腔 / 陈词打标 + 位置长度加权 + 排序，Markdown / JSON 双输出，支持 stdin。
- **八型句式骨架**：反常识反转 / 本质揭露 / 痛点戳心 / 对比落差 / 数字压缩 / 定义重构 / 态度宣言 / 留白余味，每型配正例、反例、失效原因。
- **原创模式**：只给主题不给原文时，先定位读者的具体处境，再写他不敢说出口的那句话。
- **传播力可算**：`反转×1.3 + 戳心×1.2 + 共鸣×1.0 + 余味×0.8 − 字数惩罚`，排序有依据，不是拍脑袋。

## 库用法

环境：Python 3，零第三方依赖。

**通读定位核心冲突 → 跑漏斗 → 按骨架改写 → 分类标注 → 按传播力排序**

```bash
python scripts/scan.py article.txt --top 12
python scripts/scan.py article.txt --all --json
python scripts/scan.py --explain
```

## ⚠️ 最重要的一条：第一层是筛子，不是裁判

脚本跑完，**必须再人工扫一遍对称句式**。

实测：脚本排名第一的是「听着很唬人，但其实很简单」（4.5 分）——那是过渡句，被人工淘汰。

而全文最强的句子之一：

> 你看到的是它在埋头干活，后台发生的是 Token 持续流动。

28 字、在段中、一个判断词都没有，脚本只给 1.5 分，**根本没进候选池**，是人工捞回来的。

靠对仗和画面取胜的句子，正则抓不住。人工复核的关键词式：`不是…是` / `你看到的…后台发生的是` / `有人…有人`。

## 六条质量红线

1. 禁鸡汤空话
2. 禁 AI 排比腔（三段排比、对称成瘾）
3. 禁感叹号滥用
4. 禁格言体、名人名言腔
5. **查不到出处的名人语录一律不用**
6. 每句 12-40 字，超了就砍

## 打磨五步

**砍 → 换 → 短 → 收 → 读**

砍掉从句，换掉抽象词，压到最短，收一个有力的尾字，最后读出声——读着卡的句子，读者看着也卡。

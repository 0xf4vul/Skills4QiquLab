# Output Template — Golden Quote Miner

固定输出格式。每句都要带标注，否则交付物不可用。

```markdown
| # | 金句 | 类型 | 情绪 | 推荐位置 | 适用场景 |
|---|------|------|------|----------|----------|
| 01 | … | 定义重构 | 冷静 | 开篇钩子 | 公众号首段 |
| 02 | … | 痛点戳心 | 扎心 | 小标题 | 正文中段 |
```

## 字段说明

**类型** —— 八选一：

| 类型 | 骨架 |
|---|---|
| 反常识反转 | 大家都以为 A，其实 B |
| 本质揭露 | X 最了不起的地方，是…… |
| 痛点戳心 | 最怕的不是 X，是 Y |
| 对比落差 | 你看到的是 A，实际发生的是 B |
| 数字压缩 | 三件事：…… |
| 定义重构 | 所谓 X，是 Y |
| 态度宣言 | 我就是要…… |
| 留白余味 | 不说透，给画面 |

**情绪** —— 反转 / 戳心 / 共鸣 / 余味 / 冷静

**推荐位置** —— 开篇钩子 / 小标题 / 段尾点睛 / 结尾升华

**适用场景** —— 公众号 / 小红书 / 视频号口播 / 金句卡 / 朋友圈

## 收尾三件事

输出表格后，必须附上：

1. **备用句**：被淘汰但可用的 2-3 句，标明淘汰原因（过渡句 / 超字数 / 依赖上下文）。
2. **改写痕迹**：至少 2 句给出原文对照 + 改了什么、为什么。
3. **自检结果**：骨架分布、字数区间、感叹号计数（应为 0）、鸡汤/空话排查结论。

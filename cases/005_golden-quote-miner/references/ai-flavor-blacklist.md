# AI 味 / 鸡汤黑名单

改写完成后扫一遍，命中任一条即重写。
`scripts/lexicon.json` 的 `ai_flavor` 与 `cliche` 两个桶是本文件的机器可读子集；
本文件额外收录了**需要靠语义判断、脚本抓不到**的模式。

---

## A. 结构类（脚本抓不到，必须人工识别）

1. **三段排比连用**：「不是 A，不是 B，而是 C」——用一次是修辞，连用就是模板。
2. **对称成瘾**：每句都在对仗，节奏整齐得像印刷体。真人说话会有一两句是歪的。
3. **强行升华**：结尾必落到「人生 / 世界 / 未来 / 时代」。
4. **总结癖**：出现「综上所述 / 总而言之 / 归根结底 / 由此可见」。
5. **每段一个金句**：密度过高会稀释，全文 3–5 处足够。

## B. 词汇类（脚本可抓）

```

```

## D. 标点类

- 全文感叹号 **≤ 1 个**。金句靠结构发力，不靠标点喊。
- 省略号可作留白型金句的收尾，但全文 ≤ 2 处。
- 问句可作钩子，但连续两个反问=说教味。

## E. 事实类（硬红线）

- **查不到出处的名人语录一律不用**。网上伪造语录极多，宁可不用，不可乱用。
- 想引用时：先检索原文 → 找不到 → 改写成「有人说……」或干脆写成自己的观点句。
- 数据类金句必须能回溯到来源，否则降级为「据说/大概」。

---

## 反制动作

命中 B/C 类 → 直接删词重写句子。
命中 A 类 → 打破节奏：把最工整的那句改歪（换成长短句交错的口语）。
命中 D 类 → 删标点，靠结构而不是靠感叹号。
命中 E 类 → 删除引用，改成自己的判断句。

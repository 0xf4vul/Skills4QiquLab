# 四层漏斗 · 打分细则

第一层可由 `scripts/scan.py` 自动跑；第二至四层必须由人（agent）判断。

---

## 第一层 · 候选扫描（脚本）

| 信号 | 分值 | 说明 |
|------|------|------|
| 判断词（其实/说穿了/不是…是/所谓/本质/最怕/宁可…） | +2.0 / 个，上限 +6.0 | 见 `lexicon.json:judgment_markers` |
| AI 腔（在这个…的时代/首先其次/赋能/闭环…） | −2.0 / 个，下限 −6.0 | 见 `lexicon.json:ai_flavor` |
| 陈词滥调（努力就会成功/时间会给你答案…） | −3.0 / 个，下限 −6.0 | 见 `lexicon.json:cliche` |
| 字数 8–40 | +1.5 | 金句的舒适区 |
| 字数 <8 / >60 | −2.5 / −2.0 | 前者缺信息，后者难传播 |
| 段首 / 段尾 | +1.5 / +1.5 | 观点句的高发位置 |
| 引号内（引语） | +1.0 | 对话里的短回应常是矿脉 |
| 代词开头（这/那/他/其） | −1.5 | 不可独立，需补上下文 |

默认阈值 `≥3.0` 进下一层。候选池应 ≥ 最终数量的 3 倍，不够就调低阈值重跑。

### ⚠️ 已知漏句风险（第一层的盲区）

靠**意象 / 对仗 / 画面**取胜的句子往往一个判断词都没有，会被第一层漏掉。实测案例：

> 「你看到的是它在埋头干活，后台发生的是 Token 持续流动。」

这句话 28 字、段中、无判词 → 脚本只给 1.5 分，进不了候选池，但它是全文最强的句子之一。

**对策**：脚本跑完后，人工再扫一遍**对称句式**（「你看到的…后台发生的是…」「不是…是…」「有人…有人…」）和**具象名词密集**的句子，手动补进候选池。第一层是筛子，不是裁判。

## 第二层 · 密度过滤（人工）

对第一层的候选逐句问一句：**「这句话是在描述，还是在判断？」**

| 类型 | 判定 | 例 |
|------|------|-----|
| 纯描述（事件/动作/状态） | 淘汰 | 「他老婆问他是不是累了。」 |
| 纯数据 | 淘汰（除非压成数字型金句） | 「同比增长 23%。」 |
| 纯流程/操作 | 淘汰 | 「点击右上角即可导出。」 |
| 带判断 | 保留 | 「你不是不想换，是怕换了之后连现在的都没有。」 |

**没有观点的句子全部淘汰**，哪怕写得漂亮。

---

## 第三层 · 张力打分（人工）

四维度各打 0–3 分，总分 ≥ 4 保留。

| 维度 | 0 分 | 2 分 | 3 分 |
|------|------|------|------|
| **戳心** | 与我无关 | 有点被说中 | 不敢说出口的话被写出来 |
| **反转** | 意料之中 | 角度有点新 | 直接推翻我的既有认知 |
| **共鸣** | 只有作者懂 | 一部分人会点头 | 一说出来大家都「对，就是这样」 |
| **余味** | 读完就忘 | 会停一下 | 半天后还会想起来 |

> 四维度里**至少一项达到 3 分**，否则总分再高也只是「工整的句子」。

---

## 第四层 · 可独立检验（人工）

把句子从原文里拎出来，假装发一条朋友圈，问三个问题：

1. 没读过原文的人看得懂吗？（看不懂 → 补上下文改写，或淘汰）
2. 单独截图成立吗？（需要前后句才成立 → 淘汰）
3. 有人会转发吗？（没有转发动机 → 回到第三层重找）

到这一步剩下的，才是金句毛坯，进入八型骨架改写。

---

## 排序规则

改写完成后按传播力排序，权重：

```
传播力 = 反转×1.3 + 戳心×1.2 + 共鸣×1.0 + 余味×0.8 − 字数惩罚
字数惩罚 = max(0, (字数−30) × 0.05)
```

最强的放第 1 句（用作开篇钩子或封面文案）。
同一骨架最多占 2 席，超出的挪到「备用」。

# Quality Redlines — Golden Quote Miner

六条红线。触一条，那句就不是金句，是漂亮话。

## 1. 禁鸡汤空话

反面：「时间会给你答案」「越努力越幸运」「愿你被世界温柔以待」。
判据：把主语换成任何人、任何场景都成立 —— 那就是空话。
改法：落到具体处境。「每一步都不难，凑在一起，就是一个下午。」

## 2. 禁 AI 排比腔

反面：三段排比、对称成瘾。
判据：连着三句结构一样、字数接近，读起来像演讲稿。
改法：破掉对称，留一句短的砸在最后。

## 3. 禁感叹号滥用

反面：句尾加「！」制造情绪。
判据：情绪靠句子本身，不靠标点。整份清单**感叹号应为 0 个**。

## 4. 禁格言体、名人名言腔

反面：「真正的强者，从来不会……」
判据：像印在书签上的话，就没有活人感。

## 5. 查不到出处的名人语录一律不用

**这是硬红线，不是建议。** 编造语录会直接摧毁账号可信度。
判据：不能给出可验证出处的，一律删除，不管多贴切。

## 6. 12-40 字，超了就砍

判据：超 40 字的句子截不了图，传播时会被截断。
改法：五步打磨 —— **砍 → 换 → 短 → 收 → 读**。

## 实测：脚本抓不住什么

`scan.py` 用判词 / AI 腔 / 陈词 / 弱判断词打分，这套正则有三类盲区：

**盲区一：对仗句**。靠结构取胜，没有判断词。

> 你看到的是它在埋头干活，后台发生的是 Token 持续流动。

28 字、段中、零判断词 → 脚本 1.5 分，没进候选池。这是全文最强的句子之一。

**盲区二：过渡句高分**。「听着很唬人，但其实很简单」拿 4.5 分排第一，但它是过渡，不是金句。

**盲区三：结构型 AI 腔**。词表里没有脏词，但三段排比、强行升华、总结癖这些**结构毛病**，词表扫不出来。见 `references/ai-flavor-blacklist.md`。

## 人工复核清单

脚本跑完，逐条过：

- [ ] 扫对称句式：`不是…是` / `你看到的…后台发生的是` / `有人…有人`
- [ ] 淘汰排第一的过渡句（如果有）
- [ ] 检查有没有三段排比
- [ ] 每句读出声，卡的重写
- [ ] 感叹号计数 = 0
- [ ] 名人语录有没有出处

## 传播力权重

排序用：`反转×1.3 + 戳心×1.2 + 共鸣×1.0 + 余味×0.8 − 字数惩罚`

排序不等于筛选。分数高的候选仍可能被淘汰（过渡句），分数低的仍可能被捞回（对仗句）。

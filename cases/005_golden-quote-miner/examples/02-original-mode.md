# 案例 02 · 原创模式（没有原文，只有主题）

## 需求
「没有现成文章，就给我写几句关于『35 岁被优化』的金句，要能发社媒。」

## 第一步 · 定位读者的具体处境

不要写「职场人」，要写**具体到能被对号入座**的画面：

> 35 岁，被约谈那天上午还在改方案；下午抱着纸箱下楼，在车里坐了二十分钟才敢回家；
> 回家后老婆问今天怎么样，他说「还行」。

不敢说出口的那句话是：**「我不是被淘汰了，我是被替换成更便宜的版本了。」**

## 第二步 · 按八型骨架各写 1–2 句

| 骨架 | 草稿 |
|------|------|
| 反常识反转 | 你以为公司裁的是能力，其实裁的是性价比。 |
| 本质揭露 | 所谓优化，本质是给成本找一个体面的说法。 |
| 痛点戳心 | 最怕的不是被裁，是抱着纸箱下楼时还得跟保安点头。 |
| 对比落差 | 有人在前途，有人在钱途；你在找出路。 |
| 数字压缩 | 35 岁被优化，只需要两样东西：一张表和一句「感谢付出」。 |
| 定义重构 | 所谓中年危机，不过是退路清零的那一天。 |
| 态度宣言 | 我宁可承认自己慌了，也不想把这事说成「主动选择」。 |
| 留白余味 | 那天他把工位收拾得很干净。比他来的时候还干净。 |

## 第三步 · 去重与排序

同骨架最多 2 次（此处各 1 次，通过）。
按传播力排：反转 1.3 / 戳心 1.2 / 共鸣 1.0 / 余味 0.8 → 痛点戳心与反常识反转靠前。

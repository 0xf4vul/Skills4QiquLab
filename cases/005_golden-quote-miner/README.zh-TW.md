# 005 — 金句提煉

</div>

> 其他語言：[English](README.md) · [简体中文](README.zh-CN.md)

把一篇長內容，變成 5-12 句**能脫離原文單獨活下來**的句子。純文字交付，不依賴任何排版或繪圖流程。

## 項目亮點

- **四層篩選漏斗**：候選掃描 → 密度過濾 → 張力四維打分 → 可脫離語境檢驗。每層都有明確淘汰標準，不是憑感覺挑。
- **`scan.py` 跑第一層**：斷句 + 判詞 / AI 腔 / 陳詞打標 + 位置長度加權 + 排序，Markdown / JSON 雙輸出，支援 stdin。
- **八型句式骨架**：反常識反轉 / 本質揭露 / 痛點戳心 / 對比落差 / 數字壓縮 / 定義重構 / 態度宣言 / 留白餘味，每型配正例、反例、失效原因。
- **原創模式**：只給主題不給原文時，先定位讀者的具體處境，再寫他不敢說出口的那句話。
- **傳播力可算**：`反轉×1.3 + 戳心×1.2 + 共鳴×1.0 + 餘味×0.8 − 字數懲罰`，排序有依據，不是拍腦袋。

## 庫用法

**通讀定位核心衝突 → 跑漏斗 → 按骨架改寫 → 分類標註 → 按傳播力排序**

```bash
python scripts/scan.py article.txt --top 12
python scripts/scan.py article.txt --all --json
python scripts/scan.py --explain
```

## ⚠️ 最重要的一條：第一層是篩子，不是裁判

腳本跑完，**必須再人工掃一遍對稱句式**。

實測：腳本排名第一的是「聽著很唬人，但其實很簡單」（4.5 分）——那是過渡句，被人工淘汰。

而全文最強的句子之一：

> 你看到的是它在埋頭幹活，後台發生的是 Token 持續流動。

28 字、在段中、一個判斷詞都沒有，腳本只給 1.5 分，**根本沒進候選池**，是人工撈回來的。

靠對仗和畫面取勝的句子，正則抓不住。人工複核的關鍵句式：`不是…是` / `你看到的…後台發生的是` / `有人…有人`。

## 六條品質紅線

1. 禁雞湯空話
2. 禁 AI 排比腔（三段排比、對稱成癮）
3. 禁驚嘆號濫用
4. 禁格言體、名人名言腔
5. **查不到出處的名人語錄一律不用**
6. 每句 12-40 字，超了就砍

## 打磨五步

**砍 → 換 → 短 → 收 → 讀**

砍掉子句，換掉抽象詞，壓到最短，收一個有力的尾字，最後讀出聲——讀著卡的句子，讀者看著也卡。

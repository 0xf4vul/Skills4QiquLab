# 金句提炼

把「一篇长内容 → 5-12 句能单独活下来的句子」做成独立能力。不依赖任何排版或绘图流程，纯文本交付。

---

## 一、金句的定义

一句话能被称为金句，必须同时满足四条。缺一条就是「漂亮话」，不是金句。

| 维度 | 标准 | 反例 |
|------|------|------|
| **信息密度** | 含一个明确判断，不是在描述状态 | 「他最近很累」✗ → 「累不是因为事多，是因为没人接得住」✓ |
| **情绪张力** | 戳心、反转、共鸣，三选一，读完有反应 | 「我们要保持积极的心态」✗ |
| **结构节奏** | 短（12-40 字），有对仗/对比/递进/半截句 | 「在当前这个充满变化的时代里……」✗ |
| **可脱离语境** | 单独截图发出去，陌生人也能看懂并转发 | 依赖前文代词的句子 ✗ |

---

## 二、四层筛选漏斗

从原文里先粗筛再精筛，**候选池至少是最终数量的 3 倍**。

1. **第一层 · 候选扫描**：通读全文，标出所有「带判断的句子」——含「其实/不是…是/所谓/说穿了/越…越/真正」等转折或定性词的句子，以及所有段落的首尾句、对话中的短回应。
2. **第二层 · 密度过滤**：删掉纯描述、纯数据、纯流程的句子。**没有观点的全部淘汰。**
3. **第三层 · 张力打分**：对剩余句子按「戳心 / 反转 / 共鸣 / 余味」四维各打 0-3 分，保留总分 ≥ 4 的。
4. **第四层 · 可独立检验**：把句子从原文里单独拎出来读一遍，看不懂的直接删或补上下文改写。

---

## 三、八种句式骨架（改写打磨时用）

原文句子过关但不够利落时，按这八种骨架重写。**保留原意，只换外壳。**

1. **反常识反转**：「你以为是 A，其实是 B。」
2. **本质揭露**：「X 的本质，从来不是 A，是 B。」
3. **痛点戳心**：直接写读者不敢说出口的那句话，不评价。
4. **对比落差**：「有人 A，有人 B；而你在 C。」
5. **数字压缩**：把一段论证压成「三件事 / 两个词 / 一句话」。
6. **定义重构**：「所谓 X，不过是 Y 的另一种说法。」
7. **态度宣言**：「我宁愿 A，也不 B。」（第一人称，敢站队）
8. **留白余味**：半截句 + 省略号，不写满，让读者自己补。

> 一篇文章里**同一骨架最多用 2 次**，否则读者会闻到模板味。

---

## 四、工作流

1. **获取输入** —— 接受四种形式：直接粘贴的文本 / 本地文件路径 / URL（先抓取正文）/ 只有主题（转第五节的原创模式）。
2. **通读定位** —— 找出全文的核心冲突或核心洞察，一句话写下来。这一步不做，后面全是散句。
3. **跑漏斗第一层** —— 有文本文件的直接用脚本，别手工逐句挑：

```bash
cd scripts
python scan.py 文章.txt --top 20                 # Markdown 候选表
python scan.py 文章.txt --min-score 4 --json     # 机器消费
cat 文章.txt | python scan.py -                  # 读 stdin
python scan.py --explain                         # 查看打分规则
```

脚本负责：断句、判词/AI腔/陈词打标、位置与长度加权、排序输出候选池。
它**只跑第一层**，输出里已注明「排名≠最终金句」。第二至四层（密度过滤 / 张力打分 / 可独立检验）必须人工过，打分细则见 `references/scoring-rubric.md`。
文案量小（<10 句）或只有主题时，跳过脚本直接人工跑漏斗。

4. **打磨** —— 按第三节骨架改写，控制在 12-40 字。
5. **分类标注** —— 每句标：类型 / 情绪 / 推荐位置 / 适用场景。
6. **排序输出** —— 按「传播力」排，最强的放第一句。

### 工程目录

```
golden-quote-miner/
├── SKILL.md                    入口（本文件）
├── README.md / CHANGELOG.md / LICENSE / _meta.json
├── references/  quote-patterns.md · scoring-rubric.md · ai-flavor-blacklist.md
├── scripts/     scan.py · lexicon.json
└── examples/    sample-article.txt · 01-article-extract · 02-original-mode
```

调权重/加词条只改 `scripts/lexicon.json`（判词、AI 腔、陈词、长度、位置、阈值），改完用 `examples/sample-article.txt` 回归一次。

### 输出格式（固定）

```markdown
## 核心洞察
（一句话，全文的骨头）

## 金句清单

| # | 金句 | 类型 | 情绪 | 推荐位置 | 适用场景 |
|---|------|------|------|----------|----------|
| 1 | …… | 反常识反转 | 错愕→认同 | 开篇钩子 | 标题党/封面文案 |
| 2 | …… | 痛点戳心 | 被看见 | 第一小标题后 | 段尾点睛 |
| … | | | | | |

## 备用（未入选但可留）
- ……

## 淘汰说明
- 「……」淘汰原因：纯描述，无观点
```

推荐位置的取值固定为四选一：**开篇钩子 / 小标题 / 段尾点睛 / 结尾升华**。
适用场景从：封面文案、社媒单发、金句卡、评论区互动、标题、结尾双版本。

## 五、原创模式（无原文时）

用户只给主题不给文本时：

1. 先定**读者的具体处境**（不要「职场人」，要「35 岁被约谈后假装没事的中层」）。
2. 写出他**不敢说出口但心里认同**的那句话——这是金句的矿脉。
3. 按八种骨架各写 1-2 句，再跑第三节的同骨架去重。
4. 交付 8-12 句，按传播力排序。

---

## 六、质量红线（触碰即重写）

- ❌ 鸡汤感：努力就会成功、时间会给你答案、愿你被世界温柔以待
- ❌ 空话：重要、关键、赋能、闭环、抓手、在这个充满不确定性的时代
- ❌ AI 腔：三段排比（「不是…不是…而是…」连用）、首先/其次/最后、每一句都在对称
- ❌ 感叹号滥用：全文感叹号 ≤ 1 个；金句靠结构发力，不靠标点喊
- ❌ 编造名人名言：**查不到出处的引语一律不用**，改用「有人说」或直接写成观点句
- ❌ 格言体：像打印在墙上标语的句子（「坚持就是胜利」类）直接淘汰
- ❌ 抄袭原文长句：金句必须比原文短、比原文狠

## 七、自检清单（交付前必过）

- [ ] 每句单独截图也成立，不依赖上下文
- [ ] 每句 12-40 字，无一句是纯描述
- [ ] 八种骨架里没有哪一种用了超过 2 次
- [ ] 全文无鸡汤/空话/AI 排比腔
- [ ] 感叹号 ≤ 1
- [ ] 无编造的名人语录
- [ ] 数量达标：提炼模式 5-12 句；原创模式 8-12 句
- [ ] 每句都标了推荐位置和适用场景
- [ ] 保留了淘汰说明（让用户知道边界在哪）

## 九、独立运行说明

本技能不依赖其他任何技能，给文本或给主题都能跑。
源自内容创作体系中的「观点蒸馏层」，已剥离写作/排版/配图约束，可单独调用。

# 002 — Source-to-KOL Discovery & Account Verification

</div>

> Case ID: 002_x-account-verification

將人物名單、URL、文章、社群媒體內容、影片、Podcast、PDF、圖片、檔案或使用者貼上的內容，轉化為可驗證、可稽核的 KOL / 資訊源清單。

## Case 結構

**SKILL.md → templates → examples → evaluation → assets**

## 使用

直接閱讀 SKILL.md；需要重複執行時進入 templates/；需要參考輸入輸出時進入 examples/；需要品質檢查時進入 evaluation/。

## 輸入範圍

本 Case **不綁定單一平台**。輸入可以來自 X、LinkedIn、YouTube、Reddit、Instagram、Threads、GitHub、網頁、文章、Podcast、PDF、圖片、檔案或使用者直接提供的內容。

## 核心原則

**先確認內容中的角色，再確認人物身份，再確認帳號歸屬，最後統計活躍度與內容訊號。**

不要把所有被提及的人自動視為 KOL，也不要為了填滿表格而強行匹配帳號。

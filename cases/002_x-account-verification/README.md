# 002 — X Account Verification

</div>

> Case ID: 002_x-account-verification

将文章、Podcast、活动页中的人物名单转化为**可验证的 X 账号信息源清单**：先确认人物身份，再确认账号归属，最后统计近 30 天活跃度与内容价值。

## Case 结构

**SKILL.md → templates → examples → evaluation → assets**

## 使用

直接阅读 SKILL.md；需要批量执行时进入 templates/；需要参考输入输出时进入 examples/；需要检查质量时进入 evaluation/。

## 核心原则

**先核验身份，再统计账号；先证明“是谁”，再讨论“发了多少”。**

同名账号、第三方聚合页和搜索结果只能用于发现候选账号，不能单独证明账号属于目标人物。

## 输出重点

最终结果应区分：

**CONFIRMED / PROBABLE / UNVERIFIED / NOT_FOUND / WRONG_PERSON**

并把“近 30 天发帖数”与“原创率、AI/Tech 内容占比”分开统计，避免把单纯高频误认为高信息价值。

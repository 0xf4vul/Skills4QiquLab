# Evaluation Checklist

## Identity

- [ ] Every person comes from the specified source list.
- [ ] Every accepted X account has evidence.
- [ ] Same-name candidates were checked.
- [ ] WRONG_PERSON candidates are excluded.
- [ ] UNVERIFIED candidates are not presented as confirmed.

## Activity

- [ ] The 30-day window is explicitly stated.
- [ ] Counts are based on visible timeline evidence.
- [ ] No search-result count is used as a proxy.
- [ ] Partial access is marked.
- [ ] Original and repost activity are separated where possible.

## Content

- [ ] AI and Tech ratios use a stated sample.
- [ ] High frequency is not treated as high signal automatically.
- [ ] Recommendation reasons describe information-source value.
- [ ] No unsupported claims about the person are introduced.

## Final gate

**PASS** only if identity confidence and activity evidence are both sufficient for the claims being made.

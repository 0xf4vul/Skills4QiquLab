# Skill Builder

## Purpose
Turn a repeated task into a reusable, testable AI Skill.

## Use

Use when a repeated task should become a reusable, testable, and maintainable Skill.

## Workflow
Repeated task → define trigger → define boundaries → extract workflow → define output contract → add failure modes → build examples → evaluate → iterate.

## Skill quality test
A Skill should make a recurring task more consistent, transferable, and inspectable than an ad-hoc prompt.

## Avoid
Over-generalization / vague instructions / hidden assumptions / model-specific wording in the core layer / examples without evaluation.

## Versioning principle
When changing a Skill, record what changed and what behavior the change is intended to improve.

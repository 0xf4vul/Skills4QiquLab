# X Research

## Purpose
Research X accounts, people, posts, and topic activity using explicit, reproducible criteria.

## Workflow
Discover → verify identity → inspect recent activity → filter by criteria → compare evidence → present links and reasons.

## Criteria examples
Recent posting frequency / topical relevance / original-post ratio / engagement signals / account authenticity.

## Rule
Do not infer personal traits or political preferences from weak signals. Report observable activity and attribute claims.

## Evaluation
Identity accuracy / recency / evidence quality / criterion consistency.

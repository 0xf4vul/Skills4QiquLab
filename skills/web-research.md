# Web Research

## Purpose
Turn an open-ended research question into a traceable evidence workflow.

## Workflow
Question → scope → search → source filtering → cross-check → extract → synthesize → cite.

## Source rules
Prefer primary sources for factual claims. Use secondary sources for context and comparison. Separate documented facts from interpretation.

## Output
Answer the question directly, identify important uncertainty, and attach sources to material claims.

## Failure modes
Search-result overreliance / outdated information / single-source conclusions / mixing historical and current facts / uncited claims.

## Evaluation
Relevance / source quality / freshness / cross-checking / citation coverage.

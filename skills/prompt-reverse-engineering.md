# Prompt Reverse Engineering

## Purpose
Turn a strong existing prompt into a reusable pattern without blindly copying its wording.

## Use

Use when a strong prompt needs to be decomposed into a reusable structure or template.

## Workflow
Observe output → identify controllable variables → group variables by function → separate stable structure from instance details → create a reusable template → test on a new input.

## Extraction layers
Goal / subject / action / environment / composition / camera / lighting / material / style / constraints / output format.

## Rule
Copy the underlying decision structure, not merely the vocabulary.

## Evaluation
Transferability / controllability / clarity / preservation of important variables.

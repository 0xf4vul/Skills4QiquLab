# Prompt Optimization

## Purpose
Improve prompt clarity and execution reliability without changing the user's intended result.

## Workflow
Understand intent → extract constraints → identify ambiguity → restructure → add only necessary specificity → validate against the original.

## Preserve
Subject, action, context, style, composition, temporal order, required output format, and explicit exclusions.

## Avoid
Inventing requirements, adding fashionable buzzwords, over-specifying subjective details, or optimizing for prompt length alone.

## Evaluation
Intent fidelity / constraint coverage / ambiguity reduction / usefulness / robustness.
